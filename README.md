# rock-paper-scissors in (C++)
A console-based Rock Paper Scissors game implemented in C++ using *procedural Programming* (Functions, Enums, arrays, and Struct) the player against the computer for a customizable number of rounds, with a details final summary declaring the overall winner. 

# Features:
- Player vs computer: Player against a computer opponent with random choice generation.
- Customizable rounds: the posiblelity of choose number of rounds from [1 to 100] With build in validation.
- Round by round results: Display choices, round winner each round.
- Final game summary: Tracks player wins, computer wins, and draws to declare the ultimate Winner at the end of the game.

# Concepts & Tech stack:
- Language: C++ (procedural Programming).
- Data structures: Custom `enum` for game choices/results and `struct` for game metrics.
- Randomization: `rand()` seeded with system time (`srand((unsigned) time (NULL)`) for unbiased computer decisions.
- Functions: Modular function architecture tor game logic, validation and screen rendering.
